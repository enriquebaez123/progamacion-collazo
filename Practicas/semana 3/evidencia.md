# Semana 03 - Estructuras de decisión

## Objetivo

El objetivo de esta práctica fue aprender a utilizar estructuras de decisión
en C++ para que un programa pueda tomar diferentes caminos dependiendo de
los datos introducidos por el usuario.

## Primera decisión con if

Utilicé `if` para ejecutar una acción cuando una condición es verdadera.

Por ejemplo:

```cpp
if (distancia >= 50) {
    cout << "Entrenamiento excelente." << endl;
}
